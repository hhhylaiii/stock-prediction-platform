# 實驗：k4-return（return-1109）

> 財報修正後資料（篩選 p3-final-20261109），本機實驗分支 exp/p4-k4-target-features（6aa171d，develop 93302e0 加一個 commit，未 push），窗長 w60，seed 0；第一組沿用快取；新組多的五個特徵和排名候選設計 cand60 多的五個逐一相同；K4 的採用規則照使用者 2026-11-11 同意的規則另判，不看下面工具的判定

- w60-nomarket：只用篩選後的個股特徵，不加市場特徵
- w60-nomarket-k4：同 nomarket，再加排名第二批加入的 chip 4 個與 `fund_days_to_ex_date`
- w60-nomarket 讀 55 個特徵，清單雜湊 `15823336d71e`
- w60-nomarket-k4 讀 60 個特徵，清單雜湊 `54d4336bc87f`
- w60-nomarket-k4 比 w60-nomarket 多 5 個：`chip_day_trade_ratio_5d`、`chip_fi_holding_chg_20d`、`chip_it_net_20d`、`chip_fi_buy_streak`、`fund_days_to_ex_date`
- 訓練窗：rolling 60 個月，驗證段 6 個月
- 比較 18 個研究摺（摺 4–21），seed 0；每組的快取 run_key 為 `return-1109-<組名>`，seed 不是 0 時再加 `-s<seed>`
- 判定規則：w60-nomarket-k4 的 MAE 要低於 w60-nomarket，而且逐摺差的 NW t 要低於 −2 才採用（SPEC §7：「同一組特徵訓練三類目標」；逐摺差的 NW t 門檻是實驗另加的）；其他欄只列參考。各 seed 先逐日平均，再看研究期與逐摺差
- 新組多的五個個股特徵就是排名第二批加入的那五個，兩組都不加市場特徵；下面的判定是工具的通用規則，K4 的採用規則另訂
